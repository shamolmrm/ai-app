# Firebase Setup Guide — AI Assistant App

Follow these steps IN ORDER. Each step is simple and takes about 2-3 minutes total.

---

## STEP 1 — Create a Firebase Project

1. Open your browser and go to: https://console.firebase.google.com
2. Sign in with your Google account
3. Click **"Create a project"**
4. Enter project name: `ai-assistant-app` (or any name you like)
5. Click **Continue** → **Continue** → **Create project**
6. Click **Continue** when it finishes

---

## STEP 2 — Enable Authentication

1. In your Firebase project, click **Authentication** in the left menu
2. Click **Get started**
3. Click **Email/Password** provider
4. Toggle **Enable** ON
5. Click **Save**

---

## STEP 3 — Create Firestore Database

1. In the left menu, click **Firestore Database**
2. Click **Create database**
3. Choose **Start in production mode**
4. Choose your nearest server location (e.g. us-central)
5. Click **Enable**

After it's created, click **Rules** tab and paste these rules, then **Publish**:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      match /chats/{chatId} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
        match /messages/{messageId} {
          allow read, write: if request.auth != null && request.auth.uid == userId;
        }
      }
    }
  }
}
```

---

## STEP 4 — Add Android App to Firebase

1. In Firebase Console, click the **Android icon** (⚙ gear icon → Project settings → Add app → Android)
2. Enter Android package name exactly: `com.aiassistant.ai_assistant`
3. App nickname: `AI Assistant Android`
4. Click **Register app**
5. Click **Download google-services.json**
6. **Replace** the file at this path with your downloaded file:
   ```
   d:\devloper\app\ai-app\android\app\google-services.json
   ```
7. Click **Next** → **Next** → **Continue to console**

---

## STEP 5 — Add iOS App to Firebase

1. In Firebase Console, click **Add app → iOS**
2. Enter iOS bundle ID exactly: `com.aiassistant.aiAssistant`
3. App nickname: `AI Assistant iOS`
4. Click **Register app**
5. Click **Download GoogleService-Info.plist**
6. Place the downloaded file at:
   ```
   d:\devloper\app\ai-app\ios\Runner\GoogleService-Info.plist
   ```
7. Click **Next** → **Next** → **Continue to console**

---

## STEP 6 — Install FlutterFire CLI & Generate firebase_options.dart

Open PowerShell (or your terminal) and run these commands one by one:

```powershell
# Install FlutterFire CLI globally
dart pub global activate flutterfire_cli

# Navigate to your project
cd "d:\devloper\app\ai-app"

# Auto-generate firebase_options.dart (links your app to Firebase)
flutterfire configure
```

When prompted:
- Select your Firebase project from the list
- Select platforms: Android and iOS
- Press Enter to confirm

This replaces the placeholder `lib\firebase_options.dart` with your real Firebase credentials.

---

## STEP 7 — Get Your AI API Key

### Option A — Anthropic (Claude) — RECOMMENDED
1. Go to: https://console.anthropic.com
2. Sign up / Sign in
3. Go to **API Keys** → **Create Key**
4. Copy the key (starts with `sk-ant-...`)

### Option B — OpenAI (GPT)
1. Go to: https://platform.openai.com
2. Sign in → **API Keys** → **Create new secret key**
3. Copy the key (starts with `sk-...`)

---

## STEP 8 — Run the App

```powershell
cd "d:\devloper\app\ai-app"
flutter run
```

- To run on Android emulator: open Android Studio, start an AVD, then `flutter run`
- To run on a real Android phone: enable USB Debugging, plug in, then `flutter run`
- To run on iOS simulator (Mac only): `flutter run`

---

## STEP 9 — Enter Your API Key In the App

1. Open the app → Sign up with your email
2. Go to **Profile** (top-right avatar)
3. Under **AI Configuration**:
   - Select your provider (Claude or GPT)
   - Paste your API key
   - Optionally enter a custom model ID
4. Tap **Save Settings**
5. Go back to Home → Start chatting!

## Common Questions

**Q: The app shows "API key not configured"**
→ Go to Profile screen and paste your Anthropic or OpenAI key.

**Q: firebase_options.dart shows errors**
→ You need to run `flutterfire configure` (Step 6) to replace the placeholder file.

**Q: Build fails on Android**
→ Make sure you replaced `google-services.json` with the real one from Firebase.

**Q: I want to use a fine-tuned model**
→ In Profile screen, enter your custom model ID in the "Custom Model ID" field.
   For Anthropic: your fine-tuned model ID from console.anthropic.com
   For OpenAI: your fine-tuned model ID from platform.openai.com/fine-tuning
